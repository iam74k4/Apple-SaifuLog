# SaifuLog

**ひとことで記録できる、iPhone の家計簿アプリ。**

チャットのように「ランチ 850」と一行送るだけで、支出が記録されます。文章の理解は
iPhone の中の AI が行い、記録も端末の中にだけ保存します。サーバーはありません。

> **開発中です。まだ App Store では公開していません。**
> いま動くのは、ひとこと入力の試作だけです。端末内の AI で文を読み（使えない iPhone では
> キーワード辞書で読み）、タイムラインに記録し、記録の直後に取り消せます。ホームには今月の
> 支出と収入の合計が出ます。直す・予算・レシート・質問・まとめ・設定・プレミアムはまだありません。

> **iOS 26 以降の iPhone が必要です。** iPad には対応しません。

---

## 主な機能

「試作」はいまのリポジトリで動くもの、「予定」はまだ無いものです。

| | | 状態 |
|---|---|---|
| **ひとこと入力** | 「ランチ 850」と一行送るだけで記録。記録はチャットの吹き出しのようにタイムラインに並びます | 試作 |
| **文章をそのまま理解** | 「昨日 焼肉12000 4人で割り勘」のような文を、端末内の AI が日付・カテゴリ・自分の負担額に分けて記録します | 試作 |
| **レシート・スクショの読み取り** | 写真やスクリーンショットから、明細ごとにカテゴリを仕分けます | 予定 |
| **家計に質問** | 「今月カフェにいくら使った？」のように、記録と同じ入力欄から聞けます。数字はアプリが計算します | 予定 |
| **今月の残り** | ホームに「今月あと ¥…」を表示します。予算は最初に決めます | 予定（いまは今月の支出と収入の合計だけ） |
| **月のまとめ・週のふりかえり** | 月ごとのカテゴリ別の内訳と、1週間の使い方を短いメッセージでふりかえります | 予定 |
| **書き出しとバックアップ** | CSV 書き出しと iCloud へのバックアップ（方式は検討中）。無料で使えます | 予定 |

記録した直後に「直す」「取り消す」を出すので、AI が読み違えてもその場で直せます
（いまの試作にあるのは「取り消す」だけです）。自信がないときだけ AI が聞き返し、
直した内容は次から覚える予定です。

---

## 動作要件

- **iOS 26 以降の iPhone** — 端末内の AI（Apple の Foundation Models）が iOS 26 からのため
  - iPad には対応しません
- **AI による文章の理解は、Apple Intelligence に対応した iPhone のみ**（iPhone 15 Pro 以降など）
  - 設定で Apple Intelligence をオンにし、モデルのダウンロードが済んでいる必要があります
  - 対応していない iPhone や、Apple Intelligence がオフのときは、キーワード辞書による
    解析に切り替わります。「ランチ 850」のような入力は、AI が無くても記録できます
- **レシートの画像からの読み取りは、iOS 27 で加わった画像入力を使う予定です。** iOS 26 で
  どこまで対応するか（文字認識の結果を AI に渡すなど）は検討中です

## 価格（予定）

**基本無料**で、広告はありません。ひとこと入力と AI の文章理解は、無料のまま回数の
制限なく使えます。AI は端末の中で動くため、使うほど費用がかかる仕組みではないからです。

より多く使う方向けに**プレミアム**を用意します。**買い切り ¥1,800** で、サブスクでは
ありません。ファミリー共有に対応し、家族も同じ購入で使えます。

| | 無料 | プレミアム |
|---|---|---|
| **ひとこと入力・AI の文章理解** | 無制限 | 無制限 |
| **レシート・スクショの読み取り** | 月5回 | 無制限 |
| **家計に質問** | 月10回 | 無制限 |
| **週のふりかえり** | 簡易版 | ○ |
| **月の AI レポートと予算の提案** | — | ○ |
| **予算** | 全体の予算 | カテゴリ別の予算も |
| **家族・パートナーと記録を共有** | — | ○ |
| **iCloud バックアップ・CSV 書き出し** | ○ | ○ |

**最初の 14 日間は、すべての機能を無料で使えます。** 支払い情報の登録は要りません。
バックアップと書き出しを無料にしているのは、記録したデータを人質にしないためです。

購入と復元は App Store が扱います。アカウントの登録は要りません。価格と無料の回数は
予定で、リリースまでに変わることがあります。

## プライバシー

- **家計の記録は、お使いの iPhone の中にだけ保存します。** 開発者のサーバーは
  ありません。記録を外部へ送ることもありません
- **AI の処理も端末内です。** 入力した文章やレシートの画像を、解析のために外部へ
  送ることはありません
- **広告・解析ツール・トラッキングはありません**
- **iCloud との同期や家族との共有は、将来の任意の機能です。** 利用者が有効にしたときだけ、
  利用者自身の iCloud（Apple）を通じて行う予定です

詳しくは [`PRIVACY.md`](PRIVACY.md) を参照してください。

## ソースからビルドする

ビルドには **Xcode 27 以降**と、プロジェクトを生成する
[XcodeGen](https://github.com/yonaskolb/XcodeGen) が必要です。

```bash
brew install xcodegen
git clone https://github.com/iam74k4/SaifuLog-Apple.git
cd SaifuLog-Apple
make generate
make open
```

`make generate` が `project.yml` から `SaifuLog.xcodeproj` を作り、`make open` が
Xcode で開きます。スキーム **SaifuLog** とシミュレータを選んで実行してください。
`SaifuLog.xcodeproj` は生成物なので、コミットしません。設定を変えるときは
`project.yml` と `Config/Base.xcconfig` を編集し、`make generate` で作り直します。

| コマンド | 内容 |
|---|---|
| `make generate` | `project.yml` から `SaifuLog.xcodeproj` を生成する |
| `make open` | 生成したプロジェクトを Xcode で開く |
| `make build` | 生成してから、シミュレータ向けに署名なしでビルドする。CI と同じ経路です |
| `make test` | 計算や解析を受け持つ `Packages/SaifuLogCore` のテストを実行する |
| `make check-version` | アプリのバージョンと `CHANGELOG.md` の先頭の見出しが一致しているか確かめる |
| `make clean` | ビルドの生成物を消す |

シミュレータで AI の機能を試すには、Mac 側でも Apple Intelligence が有効になっている
必要があります。実機で動かすときは、署名のチーム（`DEVELOPMENT_TEAM`）をご自身の
ものに置き換えてください。`Config/Secrets.xcconfig` を作って `DEVELOPMENT_TEAM = <チーム ID>` と
書けば、追跡しているファイルを変えずに上書きできます（このファイルは `.gitignore` 済みです）。

## ブランチ運用とリリース

- **`main`** はリリース済みの版だけ、**`develop`** は統合用です。作業は `develop` から
  ブランチを切り、PR でマージします。コミットは Conventional Commits で書きます
  （詳しくは [`CLAUDE.md`](CLAUDE.md)）
- PR では CI（`build`）が `make build`・`make test`・`make check-version` と、署名なしの
  `make archive`（提出物と同じ組み立て）を通します
- **`main` へのマージがリリースの合図です。** App Store Connect へのアップロードと
  審査への提出が自動で進み、配信が始まるとタグ `v<バージョン>` と GitHub Release が
  自動で作られます
- バージョンの正は `Config/Base.xcconfig` の `MARKETING_VERSION` です。`CHANGELOG.md` の
  各バージョンの節は、そのまま App Store のリリースノートになります

手順と一度だけの準備は [`docs/release-flow.md`](docs/release-flow.md) にまとめています。

## 仕組み

ひとこと入力の読み取りと保存（下の 1〜3 のうち「直す」を除く部分）は試作済みです。
「直す」と質問、平均・残りの計算は予定です。

1. 入力欄に一行を送る
2. 端末内の AI（Foundation Models のガイド付き生成）が、日付・金額・カテゴリ・メモを
   決められた形で取り出す
3. 割り勘の割り算や、合計・平均・残りの計算はアプリのコードで行い、SwiftData で端末内に
   保存する。タイムラインに吹き出しで出し、すぐ「直す」「取り消す」を示す

計算を AI に任せないのは、端末内のモデルが小さく、数字を間違えることがあるためです。
AI は文章から値を取り出すことと、質問への答えの言い回しだけを受け持ちます。

| 入力 | 記録のされ方 |
|---|---|
| ランチ 850 | 食費 ¥850 |
| 昨日 焼肉12000 4人で割り勘 | 前日の日付で、食費 ¥3,000（立て替えた ¥9,000 はメモに残す） |
| スーパー2480とドラッグ1200 | 2件に分けて記録する |
| 給料 25万 | 収入 ¥250,000 |

Apple Intelligence を使えない iPhone では、キーワード辞書で金額とカテゴリを読み取る
方式に切り替わります。自然な文章の理解は弱くなりますが、記録はそのままできます。

## 既知の制約

- **iPad と Mac には対応しません。** 最初の版は iPhone に絞っています
- **AI による文章の理解は、Apple Intelligence に対応した iPhone でしか働きません。**
  それ以外ではキーワード辞書による解析になり、割り勘や複数件の入力は読み取れないことがあります
- **端末内の AI は読み違えることがあります。** そのため計算はさせず、記録の直後に
  取り消せるようにしています。直す機能と、直した内容を覚える仕組みは予定です
- **サーバーを持たないため、機種変更での引き継ぎは、いまは iOS のバックアップ
  （iCloud バックアップや Mac・PC へのバックアップ）に頼ります。** CSV 書き出しと、
  アプリとしての iCloud へのバックアップは予定です
- **金額は、いまのところ日本円を前提に設計しています**
