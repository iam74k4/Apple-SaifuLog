# App Store の掲載情報（日本語）の下書き

App Store Connect の「日本語」のローカライズに入れる文の下書き。**入力は所有者が内容を確かめてから行う**（このファイルを
書き換えても App Store Connect には反映されない）。英語は [`metadata.en.md`](metadata.en.md)。

書き方の決まり:

- 実装して App Store へ出すビルドに入っている機能だけを書く。予定の機能や、App Store へ出すビルドで無効にしている機能は書かない。
- AI の機能は「Apple Intelligence に対応した iPhone で使える」と書き、AI が使えなくても記録できることを添える（Foundation Models は
  Apple Intelligence に対応した端末で、Apple Intelligence がオンでモデルの準備が済んでいるときだけ使える）。
- 名前・サブタイトル・スクリーンショットには価格を入れない（審査ガイドライン 2.3.7）。価格は説明にだけ書く。
- キーワードには、アプリ名・カテゴリ名・他社のアプリ名・価格の語（「無料」など）を入れない。
- 文を変えたら、下の「文字数」の表を数え直す（`python3` で数えた値。キーワードは UTF-8 のバイト数）。

## アプリ名

App Store Connect に「サイフログ」で登録済み（ホーム画面の表示名 `CFBundleDisplayName` の日本語と同じ）。そのまま使う。
説明の語（「家計簿」など）は名前に足さず、サブタイトルに置く（名前に語を詰め込むのはガイドライン 2.3.7 に触れやすく、
ホーム画面の名前とも食い違うため）。

```text
サイフログ
```

## サブタイトル

```text
ひとことで記録できる家計簿
```

別の案: 「ひとことで家計簿」（`docs/design.md` §10 の最初の案。短く言い切れるが、何ができるかは伝わりにくい）。

## プロモーション用テキスト

審査を通さずにいつでも差し替えられる欄。季節の案内や新しい機能の知らせに使う。価格は書かない。

```text
「ランチ 850」と送るだけ、Apple Pay で払うだけで記録できる家計簿。文章もレシートも声も iPhone の中で読み取ります。開発者のサーバーはなく、銀行やカードのログインも要りません。
```

## 説明

App Store は Markdown を表示しないので、見出しは「■」、箇条書きは「・」で書く。

```text
「ランチ 850」と送るだけ。チャットのように、ひとことで記録できる家計簿です。Apple Pay で払えば、それだけで記録にもなります。

文章の読み取りも、レシートの文字の読み取りも、声の書き起こしも、iPhone の中で行います。開発者のサーバーはなく、家計の記録を開発者に送ることはありません。銀行やカードのログインも要りません。

■ 払うだけで記録（Apple Pay）
・「ショートカット」App のオートメーションを一度作れば、Apple Pay で払ったときに金額と店名を受け取り、次に開いたときに記録してお知らせします。作り方は設定にあります。
・金額はウォレットの値のまま、カテゴリはお店の名前で決めます。分からないお店は一度だけ聞き、次から覚えて使います。違っていたら、その場で取り消せます。
・受け取った支払いは iPhone の中だけで扱います。

■ ひとことで記録
・「ランチ 850」「昨日 焼肉12000 4人で割り勘」「給料 25万」のように送るだけで、日付・カテゴリ・金額に分けて記録します。
・続けて書いた複数の記録、「昨日」「9/26」のような日付、割り勘、値引きも読み取ります。
・Apple Intelligence に対応した iPhone では端末内の AI が文章を読み、それ以外の iPhone ではキーワード辞書で読みます。AI が使えなくても記録できます。
・割り勘の割り算や合計・残りの計算は、AI ではなくアプリが行います。
・記録の直後に「直す」「取り消す」を出すので、読み違いはその場で直せます。あとからでも、記録を押して直したり、長押しで削除したりできます。
・カテゴリが分からない記録は返事の中で聞き、選んだカテゴリを覚えて次から使います。家賃・服・美容のようなカテゴリも作れます。
・よく記録する品目は入力欄の上にボタンで並び、押して送るだけで記録できます。

■ 毎月の記録は自動で
・家賃・サブスク・給料のように毎月同じものを「くり返しの記録」にすると、決めた日を過ぎて開いたときに記録します。記録を長押しして「毎月くり返す」からも作れます。

■ Siri・ショートカット
・「サイフログで記録」と Siri に話すと、アプリが開いて記録します。家計への質問・レシート・声の入力も、Siri・ショートカット・アクションボタンから使えます。

■ レシートを読み取る
・カメラで撮るか、写真やスクリーンショットから選ぶと、店名・日付・品目・合計を読み取り、品目ごとにカテゴリを仕分けます。
・品目の合計とレシートの合計を照らし合わせ、確かめてから記録します。まとめて 1 件で記録することもできます。
・画像は iPhone の中で読み取り、保存も送信もしません。

■ 声で入力
・マイクのボタンを押して話すと、iPhone の中で文字にして入力欄に入れます。送信は自分で押すので、書き起こしを確かめてから記録できます。
・声は保存も送信もしません。はじめて使うときに、日本語の音声モデルのダウンロードが必要なことがあります（声の入力に対応していない iPhone では、マイクのボタンは出ません）。

■ 家計に質問
・同じ入力欄で「今月カフェいくら?」「先月の食費は?」「今月あと何日でいくら使える?」のように聞けます。
・数字はアプリが記録から計算し、期間と元になった記録の件数を添えて答えます。前の期間との比べ（「先月の同じ日までより ¥1,800 多い」）と 6 か月の推移も添え、続けて聞ける質問をボタンで出します。

■ 予算・月のまとめ・週のふりかえり
・月の予算を決めると、ホームに「今月あと ¥…」と、月末まで 1 日あたりに使える額、今日までの目安より多いか少ないかを表示します。
・月のまとめでは、月ごとの支出・収入・収支、1 日あたりの平均、前の月との差、カテゴリ別の内訳を確かめられます。
・プレミアムでは、食費やカフェなどカテゴリごとにも予算を決められ、月のまとめのカテゴリの行で、使った額と予算、残り（超えたら超えた額）を確かめられます。
・週が替わって最初に開くと、先週の支出と前の週との差、多く使ったカテゴリをまとめた「先週のふりかえり」を出します。予算を決めていないときなどは、直近の支出から月の予算の目安を示します。

■ 書き出しと同期
・記録を CSV ファイル（UTF-8・BOM 付きで、表計算アプリでも文字化けしません）に書き出せます。期間は今月・先月・今年・すべてから選べます。
・設定で「iCloud で同期」をオンにすると、同じ Apple アカウントの iPhone どうしで記録と予算をそろえます（既定はオフ）。保存先は自分の iCloud で、開発者は中身を見られません。

■ プライバシー
・家計の記録は iPhone の中に保存します（「iCloud で同期」をオンにしたときは、自分の iCloud にも保存します）。
・Face ID（または Touch ID・パスコード）でアプリをロックできます。
・解析ツール・広告・トラッキングはありません。アプリから開発者へデータを送ることはありません。

■ 料金
・基本無料で、広告はありません。ひとこと入力（AI の読み取りを含む）・Apple Pay の支払いの記録・くり返しの記録・声の入力・予算・月のまとめ・週のふりかえり・CSV 書き出し・iCloud 同期は、無料で回数の制限なく使えます。
・無料では、レシートの読み取りは月 5 回（記録したときだけ数えます）、家計への質問は月 10 回まで使えます。
・プレミアム（買い切り ¥1,800。サブスクではありません）では、レシートの読み取りと家計への質問の回数の制限がなくなり、先週のふりかえりと月のまとめに端末内の AI の一言が付き（Apple Intelligence に対応した iPhone のみ）、カテゴリ別の予算を決めて月のまとめで使った額と比べられます。ファミリー共有に対応しています。
・14 日間、プレミアムの機能を無料で試せます（1 つの Apple アカウントにつき 1 回）。体験は 0 円で、終わっても自動で課金されることはありません。続けて使うときだけ、プレミアムを購入してください。
・価格は日本の App Store のものです。

■ 動作環境
・iOS 26 以降の iPhone。
・端末内の AI を使う機能（文章の読み取り・質問の答えに添える一言・ふりかえりの一言・レシートの品名とカテゴリの整え）は、Apple Intelligence に対応した iPhone で、Apple Intelligence がオンになっていて、モデルのダウンロードが済んでいるときに使えます。
・Apple Pay の支払いの記録は、「ショートカット」App でオートメーションを作ったときに使えます。円の支払いだけを記録します。
・入力の読み取りは日本語の文を前提にしています。金額は円で記録します。

プライバシーポリシー: https://github.com/iam74k4/SaifuLog-Apple/blob/main/PRIVACY.md
```

説明の中身は README の「主な機能」「価格」と、`docs/design.md` §6 の料金表に合わせている。機能を足したり料金を変えたりしたら、
ここも直す。

- **カテゴリ別の予算:** 額を決める欄（予算の画面）と、月のまとめのカテゴリの行の進み（使った額と予算・残りか超えた額）を出している
  （プレミアムと体験中だけ。`docs/design.md` §6-1）。ホームの帯には出さず、家計への質問も全体の予算だけで答えるので、帯に出るようにも、
  カテゴリ別の予算の残りを聞けるようにも書かない。
- **「アプリから開発者へデータを送ることはありません」:** App のプライバシーの回答（[`privacy-answers.md`](privacy-answers.md)）の
  「データの収集なし」と同じ意味。「開発者が受け取るデータはありません」とは書かない。「App デベロッパと共有」をオンにしている
  利用者のクラッシュの記録などの診断データは、Apple から開発者に届くことがあるため（`PRIVACY.md` の「収集する情報」、
  `privacy-answers.md` のクラッシュの記録の行。英語の説明の「The developer receives no data from the app.」も同じ範囲）。
  回答を変えたら、この行も直す。

## キーワード

カンマで区切り、空白を入れない。名前（サイフログ）・サブタイトル（家計簿・記録）・カテゴリ（ファイナンス）と重なる語は、
App Store がそちらで拾うので入れない。他社のアプリ名と価格の語（「無料」「買い切り」）も入れない。

```text
支出,節約,予算,レシート,出費,お小遣い,AI,音声入力,チャット,割り勘
```

## カテゴリ

| | カテゴリ | 理由 |
|---|---|---|
| プライマリ | ファイナンス | 家計簿。`project.yml` の `LSApplicationCategoryType`（`public.app-category.finance`）と同じ |
| セカンダリ（案） | 仕事効率化 | 「ひとことで記録する」入力の速さが売りのため。別の案は「ライフスタイル」（日々の暮らしの記録として） |

## URL

| 項目 | URL | 注記 |
|---|---|---|
| サポート URL（必須） | https://github.com/iam74k4/SaifuLog-Apple/blob/main/docs/support.md | 問い合わせ先とよくある質問（[`../support.md`](../support.md)）。個人のメールアドレスは載せない |
| マーケティング URL（任意） | 入れない | 専用のページを持たない |
| プライバシーポリシー URL | https://github.com/iam74k4/SaifuLog-Apple/blob/main/PRIVACY.md | アプリの設定の「プライバシーポリシー」が開く URL と同じ（`SettingsModel.privacyPolicyURL`） |

**どちらの URL も main のファイルを指す。** main には、初めてのリリース（develop → main のマージ）まで `PRIVACY.md` も
`docs/support.md` も入っていない（いまの main は README だけ）。App Store Connect に入れる前に開けることを確かめ、
`PRIVACY.md` は草案の注記を外して施行日を入れてから審査に出す（`docs/release-flow.md` の「初回リリース（0.1.0）の進め方」の 4）。
