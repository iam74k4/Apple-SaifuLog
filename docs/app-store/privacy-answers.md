# App のプライバシーの回答案

App Store Connect → アプリ → 「App のプライバシー」に入れる回答の案と、その根拠。**入力は所有者が内容を確かめてから行う。**
方針は `docs/design.md` §11、利用者向けの説明は [`PRIVACY.md`](../../PRIVACY.md)。この 3 つを食い違わせない（データの扱いを
変えるときは、先に `PRIVACY.md` を直してから、ここと App Store Connect の回答を直す）。

## 回答

| 質問 | 回答 |
|---|---|
| プライバシーポリシーの URL | https://github.com/iam74k4/SaifuLog-Apple/blob/main/PRIVACY.md （アプリの設定から開く URL と同じ。main に入るのは初めてのリリースのとき。[`metadata.ja.md`](metadata.ja.md) の「URL」） |
| あなた、またはあなたの第三者パートナーは、この App からデータを収集しますか？ | **いいえ、この App からデータを収集しません** |

「いいえ」にすると、App Store の表示は「データの収集なし」になり、データの種類ごとの質問（連絡先情報・購入・位置情報・
ユーザコンテンツ・診断など）には答えない。トラッキング（App Tracking Transparency）も使わない。

## 根拠

App Store の「収集」は、データを端末の外へ送り、開発者やその協力者が、要求に応えるのに要る時間より長く読める状態にすること
（[Apple の説明](https://developer.apple.com/app-store/app-privacy-details/)）。同じページは、次のものを申告しなくてよいとしている。

- 端末の中だけで処理するデータ（「収集」にあたらない）。
- Apple が集めるデータ（開発者は申告しない）。
- 支払いの情報をアプリの外で入れ、開発者が読めない決済（App 内課金の支払い）。

このアプリは開発者のサーバーを持たず、解析・広告・クラッシュレポートの送信・トラッキングの SDK を 1 つも入れていない
（`docs/design.md` §11）。機能ごとの扱いは次のとおり。

| 機能 | 扱うデータ | どこで処理し、どこに置くか | 開発者が受け取るか | PRIVACY.md の節 |
|---|---|---|---|---|
| ひとこと入力・記録・予算 | 金額・日付・カテゴリ・メモ・入力した文・予算の額 | 端末の中（SwiftData。データ保護 Complete を開くたびに当てる。実機での確認はまだ。`docs/design.md` §5-4） | 受け取らない | 入力した家計の記録 |
| 端末内 AI（文章の読み取り・質問の一言・ふりかえりの一言・レシートの品名） | 入力した文・記録から計算した数字の文・レシートの品目 | 端末の中（Foundation Models）。AI が使えない端末はキーワード辞書（端末の中） | 受け取らない | 端末内 AI の取り扱い／家計への質問／週のふりかえりと月のまとめ |
| 家計への質問 | 質問の文と答え | 端末の中。保存しない（アプリを開き直すと消える）。無料で使った回数だけを UserDefaults に置く | 受け取らない | 家計への質問 |
| レシートの読み取り（カメラ・写真） | レシートの画像と読み取った文字 | 端末の中（Vision・Foundation Models）。画像も文字の全体も保存しない。記録するのは利用者が確かめた品目と、店名と合計の要約だけ。写真は PhotosPicker（利用者が選んだ 1 枚だけを受け取る。ライブラリの許可を求めない） | 受け取らない | レシート・スクリーンショットの取り扱い |
| 声の入力（マイク） | 声と書き起こした文 | 端末の中（SpeechAnalyzer）。録音を残さず、Apple のサーバーへも送らない。日本語の音声モデルは Apple からダウンロードするが、その通信に声や記録は入らない | 受け取らない | 声での入力 |
| CSV 書き出し | 選んだ期間の記録 | 利用者が操作したときだけファイルを作り、iOS の共有の画面で利用者が選んだ先にだけ渡す（アプリが自動で送らない）。一時ファイルは共有の画面を閉じたら消す | 受け取らない（渡す先は利用者が選ぶ。開発者はその先に含まれない） | CSV 書き出し |
| iCloud で同期（任意・既定オフ） | 記録と予算 | 利用者自身の iCloud の非公開データベース（CloudKit）。開発者のサーバーを通らず、開発者は中身を読めない。Apple の仕組み（CloudKit）で Apple が扱うデータは申告しない | 受け取らない | iCloud での同期（任意） |
| プレミアムの購入・体験・復元 | 購入の記録（どの商品・日時・ファミリー共有か・取り消されたか） | Apple の StoreKit。支払いはアプリの外で行い、アプリは端末の上の購入の記録を読むだけで、保存も送信もしない | 受け取らない（App Store Server Notifications なども使わない） | 購入の取り扱い |
| 設定 | 初回の案内を終えたか・週の始まり・iCloud で同期するか・アプリのロック・無料で使った回数・ふりかえりを出した日時など | 端末の中（UserDefaults。`PrivacyInfo.xcprivacy` の CA92.1。iCloud 同期とアプリのロックの 2 つは、同じ領域の設定のファイル（最初のロック解除の後は読める保護）） | 受け取らない | 保存される設定 |
| 設定・プレミアムの画面のリンク | — | Safari で GitHub（プライバシーポリシー・ライセンス）と Apple（標準 EULA）のページを開くだけ。アプリは記録や設定を送らない | 受け取らない | 設定の画面から開くページ |
| クラッシュの記録 | クラッシュの記録など | 利用者が iPhone の設定で「App デベロッパと共有」を有効にしているとき、Apple が集めて開発者に提供することがある。アプリ自身は送らない（Apple が集めるデータは申告しない） | アプリからは受け取らない | 収集する情報 |

## 見直すとき

次のどれかをしたら、この回答（と `PRIVACY.md`・`docs/design.md` §11）を見直す。どれも、開発者やその協力者がデータを受け取る
ようになり、「データの収集なし」ではなくなりうるため。

- 解析・広告・クラッシュレポートの送信などの SDK を入れる。
- 開発者のサーバーや、開発者が読める場所（CloudKit の公開データベースなど）にデータを送る・置く。
- App Store Server Notifications や App Store Server API で、購入の記録を開発者の側で受け取る。
- App Store へ出すビルドで無効にしている機能を有効にする（有効にする前に、その機能のデータの扱いをここに足す）。
