# 年齢制限の回答案

App Store Connect → アプリ → 「App 情報」→「年齢制限」に入れる回答の案。**入力は所有者が内容を確かめてから行う。**
質問の項目は、2026 年 9 月時点の Apple の説明（[Age ratings values and definitions](https://developer.apple.com/help/app-store-connect/reference/app-information/age-ratings-values-and-definitions/)）
に合わせた。入力するときの画面の項目と食い違っていたら、画面に合わせて同じ考え方で答え、このファイルを直す。

## 回答

アプリは家計簿で、記録は利用者の端末（と、利用者が選んだときは自分の iCloud）にだけ置く。ほかの利用者とのやり取り・
ほかの人が作った中身の表示・広告・アプリの中での Web の閲覧は無い。

### アプリの中の管理

| 項目 | 回答 | 理由 |
|---|---|---|
| ペアレンタルコントロール（Parental Controls） | なし | 保護者が子どもの使い方を見守る・制限する仕組みは持たない |
| 年齢の確認（Age Assurance） | なし | 年齢を確かめる仕組みは持たない（年齢によって出し分けるものが無い） |

### 機能（Capabilities）

| 項目 | 回答 | 理由 |
|---|---|---|
| 制限のない Web へのアクセス（Unrestricted Web Access） | いいえ | アプリの中に Web を閲覧する画面は無い。設定とプレミアムの画面のリンク（プライバシーポリシー・ライセンス・Apple の標準 EULA）は、決まったページを Safari で開くだけ |
| ユーザーが作成したコンテンツ（User-Generated Content） | いいえ | 記録は利用者自身のものとして端末（と自分の iCloud）に置くだけで、ほかの利用者に配ったり見せたりしない |
| ソーシャルメディア（Social Media） | いいえ | フィードや共有の仕組みは無い |
| メッセージとチャット（Messaging and Chat） | いいえ | 入力欄と記録の吹き出しはチャットに似た見た目だが、ほかの人とのやり取りではない（アプリへの入力） |
| 広告（Advertising） | いいえ | 広告を出さない |

### 内容

次の項目はすべて「なし」。

| 区分 | 項目 |
|---|---|
| 成熟したテーマ | 下品な言葉や下品なユーモア・ホラーや恐怖・アルコール、たばこ、薬物の使用や言及 |
| 医療または健康 | 医療または治療の情報・健康やウェルネスの話題 |
| 性的な内容やヌード | 成熟したテーマや示唆的なテーマ・性的な内容やヌード・露骨な性的な内容やヌード |
| 暴力 | アニメや空想の暴力・現実的な暴力・長時間の残虐な暴力・銃などの武器 |
| 偶然に左右される活動 | ギャンブル・疑似ギャンブル・コンテスト・ルートボックス |

「医療または治療の情報」は「なし」。支出のカテゴリに「医療」（病院・薬の支出を分ける）があるが、医療の情報や助言は出さない。

## 結果

**4+**（すべて「なし」「いいえ」のため）。子ども向け（Kids カテゴリ）にはしない。

地域ごとの区分（オーストラリア・ブラジル・韓国など）も、上の回答から App Store Connect が決める。特別な申告（韓国のギャンブルの
分類番号など）は要らない。

## 見直すとき

次のような機能を足したら、回答を見直す。

- アプリの中で Web ページを閲覧できる画面（決まったページでも、そこから自由にたどれるもの）。
- ほかの利用者とのやり取り、ほかの人が作った中身を見せる仕組み。
- 広告。
